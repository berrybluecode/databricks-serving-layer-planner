Calculation reference

Formulas behind every estimate

Values are calculated month by month. Month m starts at zero, so Month 1 uses the baseline and Month 12 applies eleven periods of compound growth.

Shared growth model

Monthly demand

Demandₘ = Baseline × Scenario × (1 + Growth%)ᵐ

Scenario is 0.7×, 1.0×, or 1.5× for low, base, and high.

Genie One · Agents · Code · API

Weighted token demand

Prompts = Users × Prompts/User Context = min(Cap, 1 + Growth/Msg × Avg Prior Msgs) Turns = (1 − Agent Share) + Agent Share × Agent Turns Tokens = Prompts × (Input × Context + Output) × Turns × Surface Factor

For API traffic, prompts start from requests/day × active days.

Genie calibration

Tokens to DBUs

Genie DBUs = Weighted Tokens / 1M × Observed DBUs per 1M SQL DBUs = Prompts × Queries/Prompt / 1K × Observed SQL DBUs per 1K

The conversion is user-supplied because Databricks does not publish a universal token-to-DBU rate.

AI/BI

Queries, volume, and complexity

Queries = Viewers × Sessions/Day × Queries/Session × Active Days × Cache Miss% + Refresh Queries Volume Factor = max(0.25, √(Scanned GB / Profile Reference GB)) SQL DBUs = Queries / 1K × Profile DBU Rate × Volume Factor Peak Concurrency = Peak QPS × p95 Runtime Seconds

Profiles: Light KPI tiles, Medium multi-join dashboards, Heavy wide scans/write-back, and Extreme shared app + ETL warehouses.

Databricks Apps

Runtime and dependencies

App DBUs = Instances × Hours/Day × Active Days × DBU/Instance-Hour SQL Queries = Users × Requests/User/Day × Active Days × Queries/Request SQL DBUs = SQL Queries / 1K × Complexity Rate × Volume Factor Total DBUs = App DBUs + SQL DBUs + Optional Lakebase DBUs AI Tokens = Requests × (Input Tokens + Output Tokens)

Medium uses 0.5 DBU per running instance-hour; Large uses 1 DBU. Lakebase is enabled only for write-back, state, or OLTP patterns.

Lakehouse

Physical storage

New Stored TB = Raw TB × Compression × Layer Amplification Time Travel TB = Active TB × Daily Rewrite% × Deleted Retention Days Physical TB = (Active TB × Copies + Time Travel TB) × (1 + Metadata%)

The retention window keeps only monthly additions still covered by the selected policy.

Commercial model

List price, discount, and net cost

DBU List Cost = DBUs × DBU List Price Total List Cost = DBU Cost + Token Cost + Storage Cost Discount Savings = Total List Cost × Discount Rate Net Cost = Total List Cost − Discount Savings

This deployment defaults to Azure North Europe at $0.91/DBU and a 50% account discount. Replace with the account contract where applicable.

Calibration loop

Replace assumptions with actuals.

  1. Start with a low, base, and high scenario.
  2. Run a 14–30 day pilot with representative users.
  3. Measure DBUs in system.billing.usage and prices in system.billing.list_prices.
  4. Measure Genie activity, SQL query history, AI Gateway tokens, App telemetry, and storage metrics.
  5. Recalibrate monthly and investigate forecast variance above 15%.
